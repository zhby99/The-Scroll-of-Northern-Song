# 北宋立志传
> “举目则青楼画阁，绣户珠帘。雕车竞驻于天街，宝马争驰于御路，金翠耀目，罗绮飘香；新声巧笑于柳陌花衢，按管调弦于茶坊酒肆。八荒争凑，万国咸通。集四海之珍奇，皆归市易；会寰区之异味，悉在庖厨”

公元1050年，正是北宋由盛转衰之时，但从文化，商业到科技，仍是一片欣欣向荣，范公伟业仍在，熙宁变法将至，无论庙堂之高或是江湖之远，仍是一片熙熙攘攘。夫子忧心国家力图大治，改革派保守派各执己见，江湖人士义薄云天，少林丐帮，戮力抗辽。生在一个大时代，就要做一番大事业！

## 地图设定
华夏九州，北宋，辽，西夏，吐蕃，大理，女真。
只设主要城市和重要地点（如嵩山少林等），移动类似三国志，根据地理距离除以骑马速度。

主要城市设衙门，酒馆，旅店，拳馆，书院，特殊城市比如汴梁有皇宫，洛阳有白马寺，白马书院之类的。
特殊地点（比如嵩山）特殊设置。

## 游戏内容
以开放性为主，前期实现基础玩法，后期可加dlc扩展玩法。各项能力通过数值和技能量化。

基础玩法： 商业贸易，交易。北宋商业极为自由，而且国家众多，小生意比如从福建买茶到河南卖，大生意比如从西夏辽国买马来卖（走私），从宋买酒卖到辽，以财通天下为目的。

- 扩展1-科举路线: 照为田舍郎，暮登天子堂，将相本无种，男儿当自强。北宋最为重视读书人，官员不下跪，权势之大（如范仲淹王安石变法）甚至超过皇帝。加入读书和政治系统，前期全国求学，拜访大儒，结交友人，通过科举参与朝政，实现人生目标。可扩充琴棋书画专精，达成成就系统。同时加入政治系统，允许商人，武林对政治的参与／干预／贿赂。

- 扩展2-武侠路线：昔时因，今日意，胡汉恩仇，须倾英雄泪，虽万千人吾往矣，悄立雁门，绝壁无余字。 参照天龙八部剧情改编，武功能力通过数值量化，以成为武林盟主（人脉+武功）或天下第一（武功）为目的，参与江湖快意恩仇。可选择价值方向，比如反对朝廷或助宋抗辽。

- 扩展3-富甲天下。资本主义萌芽阶段dlc，成为富可敌国的商人，通过钱庄垄断商业，可补充加入海贸系统或海贼系统。以商业成就衡量进度。

- 扩展4-将军，皇帝！
- 扩展5-海外，朝鲜日本？
此外，可通过各种条件判断来触发转移状态（DFA），并触发特定剧情（奖励／惩罚）来提高／降低游戏难度。
